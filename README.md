# DeskLib64 - 64-bit DeskLib for RISC OS 64 (AArch64)

A **64-bit port of DeskLib**, the FreeWare C library for RISC OS, built with the
[AArch64 RISC OS GCC 16 tool chain](https://github.com/robheaton/riscos-gcc16#risc-os-64-aarch64-early-preview)
(`aarch64-riscos-gcc`, with `-munixlib`). It starts from **Andrew Youll's
[DeskLib32](https://github.com/adyoull/desklib32)** (commit `957863a`, which is
upstream DeskLib master `f7469f4` with a few fixes) and changes only what 64 bits
need: the structures that the Window Manager reads and writes keep their 32-bit
layout, and DeskLib's ARM assembler veneers are C.

**Status: early.** The library builds in full (505 objects). Twenty demonstration
and test applications (`tests/hello`, `demo2`, `dialogs`, `save`, `sprite`, `pane`, `msgs`, `filing`, `colour`, `font`, `font3`, `clear`, `drag`, `clip`, `env`, `misc`, `menu2`, `controls`, `taskwindow`, `gaps`) exercise the event
system, windows, template files, icons, menus, `Dialog2` dialogue boxes, the `Save`
library with file icon drag, the `Sprite` library and panes (`Pane`, `Pane2`) and message files (`MsgTrans`, `Msgs`) files (`File`, `Filing`) colour (`ColourTrans`) and fonts with the font menu (`Font`, `Font2`). A good deal of DeskLib (printing, fonts ...)
has not been run yet: see
[docs/STATUS.md](docs/STATUS.md). Please report problems as issues.

## Changes from DeskLib32

**Every change, with the problem, evidence, reasoning, compatibility impact and
verification, is documented in [MODIFICATIONS64.md](MODIFICATIONS64.md).** The
exact edits are in [patches/desklib64-vs-desklib32.diff](patches/desklib64-vs-desklib32.diff).

In summary, `src/` is DeskLib32: 567 files are byte-identical to it, 71 are
modified and 1 is added; the 259 ARM assembler files are kept unchanged but are
not built (their SWI veneers are translated to C instead):

| | Where | Change |
|---|---|---|
| H1 | `include/Core.h` | `dl_ptr`, `DL_PTR`, `DL_P`: a pointer inside an OS structure is a 32-bit word |
| H2 | `include/Wimp.h`, `Screen.h`, `Font.h`, `PDriver.h`, `Sprite.h` | the pointer fields of the structures that the OS reads or writes are `dl_ptr`, so those structures keep their 32-bit size and layout (`window_block` is 88 bytes again) |
| H3 | `include/Menu2.h`, `Print.h` | `menu2_handle` and `print_result` are `intptr_t` (they hold pointers) |
| H4 | `include/PCI.h` | the second member `flags` of `pci_address` is `oflags` (a duplicate member name is an error in GCC) |
| H5 | `include/dl64.h` (new) | what the generated veneers need |
| C1 | 30 files in `Libraries/` | uses of the `dl_ptr` fields: `DL_P (x)` to read, `x = DL_PTR (v)` to write |
| C2 | 32 files in `Libraries/` | `(int)` casts of pointers became `(intptr_t)` (a pointer through `int` loses its top half and, from 2 GB up, its sign) |
| C3 | `Libraries/Template/Delete.c`, `Libraries/Str/LeafName.c` | `free (t->windowdef)`, not `free (&t->windowdef)`; a needless pointer cast removed |
| A1 | `gen/` | 239 ARM assembler veneers translated to C by `tools/armv2c.py` |
| A2 | `hand/` | the other veneers, and `Mem`, written by hand from the assembler |

Not built: `BackTrace` (it needs Norcroft's stack unwinding), `PCI` and `USB` (hardware specific).

## Repository layout

```
src/            DeskLib32 plus the changes in MODIFICATIONS64.md:
                  include/    DeskLib public headers
                  oldinclude/ compatibility headers
                  Libraries/  the library sources (C, and the ARM assembler that is not built)
gen/            the ARM veneers translated to C (generated by tools/armv2c.py; REGEN=1 build.sh makes them again)
hand/           veneers and Mem written by hand
tools/          armv2c.py (the assembler-to-C translator) and fixptr.py (rewrote the uses of the dl_ptr fields)
build.sh        builds dist/lib/libDeskLib64.a and dist/include/
tests/          demonstration and test applications (hello, demo2, dialogs, save, sprite, pane, msgs, filing, colour, font, font3, clear, drag, clip, env, misc, menu2, controls, taskwindow, gaps) and tests/build.sh
docs/           PORTING.md (changing a DeskLib application), STATUS.md (what has been run)
MODIFICATIONS64.md  Every change from DeskLib32 and the reason for it
patches/        The same changes as a unified diff against DeskLib32
LICENCE         DeskLib's licence, credits and contact (verbatim from upstream)
NOTICE.md       What the licence means for this repository
CHANGELOG.md    Change history
```

## Build from source

Needs the AArch64 RISC OS GCC tool chain 0.14 or newer (a Linux cross compiler) and, only to translate the assembler again, Python 3. No RISC OS hardware is needed to build.

```
./build.sh /path/to/aarch64-riscos-gcc-16.2.0-0.14-linux-x86_64     # dist/lib/libDeskLib64.a and dist/include/
tests/build.sh /path/to/the/same/tool/chain                          # dist/apps/!DLHello, !DLDemo2, !DLDialogs, !DLSave, !DLSprite, !DLPane, !DLFont, !DLFont3, !DLDrag, !DLClip, spritetest, filetest, colourtest, cleartest and msgtest
```

`dist/include/` has the headers named `DeskLib:Wimp.h` and so on, because DeskLib's sources include `"DeskLib:Wimp.h"` (a RISC OS path).

## Using it

```
aarch64-riscos-gcc -munixlib -O2 -fsigned-char -I dist/include app.c dist/lib/libDeskLib64.a -o '!MyApp/!RunImage,ff8'
```

An application is a folder with `!Run`, `!Boot` and `!RunImage` (file type &FF8); copy it to RISC OS 64 and double-click it. What an existing DeskLib application has to change is in [docs/PORTING.md](docs/PORTING.md).
